# Module Architecture Index

This directory contains detailed architecture for each module. Each file is
owned by the team member responsible for that module.

| Module | File | Owner | Status |
|--------|------|-------|--------|
| Market Data | `modules/market-data.md` | Hoàng | Active |
| Strategy Engine | `modules/strategy-engine.md` | Huy | Active |
| News & Sentiment | `modules/news-sentiment.md` | Thuận | Active |
| Event Infrastructure | `modules/event-infrastructure.md` | Phương | Active |

> ADRs (`kb/ADR/`) capture **why** decisions were made.
> Module files capture **what** the architecture looks like as a result.
> Flow files (`kb/flows/`) capture **how modules cooperate** end-to-end.
