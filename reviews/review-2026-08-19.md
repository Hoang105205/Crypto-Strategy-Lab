#### Findings

##### [MEDIUM] [F-001]: Compound Interest in Backtesting
**File**: `apps/backend/src/strategy/backtester/backtester.service.ts`
**Check**: 4a-4f (Implementation Logic)
**Issue**: The backtester calculates position sizing based on `initialCapital` on every trade (`const capitalToUse = initialCapital * ...`). It does not compound the profits/losses into the running balance for subsequent trades. 
**Impact**: The PnL reflects fixed-size trading rather than compounding. This makes the Equity Curve linear instead of exponential for highly profitable strategies.
**Action**: None required for MVP. If compounding is desired later, update the `initialCapital` reference to a running `currentCapital` variable inside the loop.

##### [LOW] [F-002]: Sharpe Ratio Calculation Approximation
**File**: `apps/backend/src/strategy/evaluator/evaluator.service.ts`
**Check**: 4a-4f (Implementation Logic)
**Issue**: The Sharpe Ratio calculates the standard deviation of `trade.pnl / initialCapital` (per-trade return) and multiplies by `Math.sqrt(252)`. This assumes exactly 1 trade per day, which is statistically inaccurate for intraday or multi-day trades.
**Action**: Acceptable approximation for this MVP. To improve, resample the equity curve into daily returns before computing the Sharpe Ratio.

##### [LOW] [F-003]: SHORT Positions Not Supported in Backtester
**File**: `apps/backend/src/strategy/backtester/backtester.service.ts`
**Check**: 4a-4f (Implementation Logic)
**Issue**: The backtester currently only opens `LONG` positions when it receives a `BUY` signal. It ignores `SELL` signals if no position is open (it doesn't short).
**Action**: Acceptable for MVP (Spot trading).

**Member verdict**: Pass with notes. Excellent implementation of the Plugin Architecture and Composite Pattern. The code is modular, UI is responsive, and bugs in the Equity Curve and Table formatting have been squashed.
