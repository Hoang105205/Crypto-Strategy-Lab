# Contract: Backtest Job Queue and Worker

## Queue Interface

```ts
interface IJobQueue {
  enqueue(
    jobType: 'BACKTEST',
    payload: BacktestRequestedPayload & { jobId: string },
    correlationId?: string,
  ): Promise<{ jobId: string }>;
  getStatus(jobId: string): Promise<JobStatus>;
  retry(jobId: string): Promise<void>;
  deadLetter(jobId: string, reason: string): Promise<void>;
  getStats(): Promise<QueueStats>;
}
```

## Validation

- `jobId` is a non-empty UUID generated by the producer and is never replaced.
- `source=USER` requires absent/null `loopRunId`.
- `source=SEARCH_LOOP` requires non-null `loopRunId`.
- Duplicate `jobId` returns conflict and creates no second execution.

## Scheduling

- Source priority: `USER` before `SEARCH_LOOP`.
- Ordering inside each source: FIFO by enqueue order.
- Default concurrency: 3.
- Attempt 1 failure → 1s wait → attempt 2.
- Attempt 2 failure → 4s wait → attempt 3.
- Attempt 3 failure → terminal dead-letter path.

## Strategy Integration Ports

```ts
interface IStrategyExecutionPort {
  resolveVersion(strategyVersionId: string): Promise<{
    version: StrategyVersion;
    strategy: IStrategy;
  } | null>;
}

interface IBacktestResultPort {
  save(input: BacktestResultCreateInput): Promise<BacktestResult>;
  getById(id: string): Promise<BacktestResult | null>;
}
```

These ports are owned/provided by Strategy Engine. Event Infrastructure does not query Strategy-owned tables.

## Terminal Events

- Success publishes exactly one `BacktestCompleted` after result persistence.
- Retryable attempt failure publishes no failure Event.
- Exhausted or non-retryable failure publishes exactly one `BacktestFailed` and one `BacktestDeadLettered`.
- Zero candles and unknown Strategy Version are non-retryable.

## Queue API

### GET `/api/queue/stats`

**200**: `QueueStats` from the active event contract.

### GET `/api/queue/dead-letter`

**200**: `DeadLetterJob[]`, newest first.

### POST `/api/queue/dead-letter/:jobId/retry`

**200**:

```json
{ "jobId": "uuid", "status": "QUEUED" }
```

**Errors**: `404 JOB_NOT_FOUND`, `409 JOB_ALREADY_RESOLVED`, `503 STRATEGY_ENGINE_UNAVAILABLE`.
